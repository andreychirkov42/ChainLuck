ChainLuck

Экзаменационный проект по децентрализованным вычислительным сетям, группа 2462. Делаем казино на смарт-контрактах, где ни игрок, ни казино не могут подкрутить результат. Ставки, банк и выплаты живут в контракте, а случайное число получается по схеме commit-reveal: казино заранее публикует хеш секрета, после ставки раскрывает сам секрет, и контракт считает результат из секрета казино и сида игрока. Если казино не раскрыло секрет вовремя, игрок забирает ставку обратно.

Всё работает только в локальной сети Hardhat, настоящие деньги не используются.

Кто что делает: Алиев Парвин пишет смарт-контракты на Solidity и Hardhat, Чирков Андрей пишет сервис-крупье на Go, Аборнев Яков делает веб-интерфейс на React и TypeScript и настраивает GitHub Actions.

Код будет лежать в трёх папках: contracts для контрактов, backend для крупье и frontend для интерфейса. Инструкции по сборке и запуску допишем, когда появится первый рабочий вариант.
